# 🧠 EduSummarize – Smart Document Summarizer for Android

**EduSummarize** is an AI-powered Android app that helps students and learners summarize and listen to study materials instantly.  
It uses AI text summarization and Text-to-Speech (TTS) to make studying faster and easier.

---

## ✨ Features

- 📸 **Scan Documents** from camera or gallery  
- 📄 **Support for PDF & DOCX** formats  
- 🤖 **AI-Powered Summarization** for study materials  
- 🔊 **Text-to-Speech Playback** of summaries  
- 📚 **Save Summaries** to personal library  
- 🔍 **Search & Filter** saved summaries easily  
- ☁️ **Firebase Integration** (Auth, Firestore, Storage)

---

## 🧩 Tech Stack

- **Android (Java / Kotlin)**  
- **Firebase** – Authentication, Firestore, Storage  
- **OpenAI API** – Text summarization  
- **Google TTS API** – Text-to-Speech  
- **Material Design 3 (Jetpack)**
